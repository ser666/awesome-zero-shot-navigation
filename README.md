## 📖 About

**What counts as "zero-shot navigation" here?** Papers where an embodied agent navigates to a goal **without task-specific training** — including zero-shot, training-free, open-vocabulary, and foundation-model / VLA-driven approaches that generalize to unseen goals or environments.

**How it works**

```
Every day (GitHub Actions, free for public repos):
  1. Harvest  → OpenAlex + Crossref (15 queries, title/abstract search)
  2. Filter   → rule-based relevance check (see scripts/relevance.py)
  3. Dedup    → DOI / arXiv ID / fuzzy title matching
  4. Export   → this README + docs/data/papers.json
  5. Deploy   → GitHub Pages
```
