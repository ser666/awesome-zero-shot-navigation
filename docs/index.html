How this works — a GitHub Actions job harvests papers every week from OpenAlex, Crossref, OpenReview and Hugging Face Papers, filters them with a self-tested rule-based relevance check, enriches them with citation counts (Semantic Scholar), open-access PDFs (Unpaywall) and code repositories (GitHub), then regenerates this page and the README list.
